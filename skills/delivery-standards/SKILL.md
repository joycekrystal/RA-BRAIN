Read references/shared-rules.md. Establish a project profile: product purpose, users, domain terms, business model, repository and stack, runtime/deployment constraints, team conventions, Jira project, Confluence space and Figma sources. Inspect existing material first and mark unknown fields explicitly. Create a concise knowledge index and standards proposal using references/templates.md. Choose only necessary artifacts; an early prototype need not have a large-company process. Route business questions to business-model, specifications to feature-specification, designs to design-review, code to feature-implementation and knowledge maintenance to knowledge-maintenance. For delivery, connect business objective → feature ID → Jira acceptance criterion → design reference → code area → test evidence → documentation. End with concrete artifacts and any decisions requiring the user.
